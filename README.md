# shire

The public site for julian-one.com — SvelteKit on adapter-node, the
only internet-facing service of the cluster. Talks server-side to
rivendell; the browser's only network peer is shire.

The service docs — routes, server/client boundary, invariants — live
in the trading-spaces workspace at `docs/shire.md` (this repo is
checked out as a sibling of that `docs/` folder).

Run: `npm run dev`
Check: `npm run check && npm run lint`
